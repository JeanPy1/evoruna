# Evoruna

**Presencia web profesional, simple y administrada.**

Evoruna es un servicio de presencia web que permite a empresas, profesionales y negocios contar con un sitio web profesional sin tener que preocuparse por el desarrollo, infraestructura o mantenimiento técnico.

## ¿Cómo funciona?

Con Evoruna, el cliente elige un plan y nosotros nos encargamos de la parte técnica.

```text
Elige tu plan
     ↓
Configuramos tu presencia web
     ↓
Publicamos tu sitio
     ↓
Nos encargamos del mantenimiento
     ↓
Solicitas cambios según tu plan
```

El cliente no necesita encargarse de servidores, configuraciones técnicas o mantenimiento del sitio.

## Nuestros planes

Evoruna ofrece diferentes planes diseñados para adaptarse a las necesidades de cada cliente.

Cada plan puede incluir diferentes niveles de:

* Características del sitio web
* Personalización
* Soporte
* Mantenimiento
* Cambios mensuales

El objetivo es ofrecer una solución clara y predecible, sin complicar al cliente con aspectos técnicos.

## ¿Qué hacemos por ti?

Nos encargamos de la parte técnica de tu presencia web:

* Desarrollo del sitio web
* Diseño y personalización
* Publicación y hosting
* Mantenimiento técnico
* Actualizaciones
* Mejoras y cambios
* Optimización del sitio

## Cambios mensuales

Cada plan incluye una cantidad determinada de cambios mensuales.

Esto permite que el sitio pueda evolucionar junto con el negocio sin necesidad de contratar cada pequeña modificación como un proyecto independiente.

Los cambios disponibles dependen del plan contratado.

## Nuestra filosofía

Evoruna busca hacer que tener una presencia web profesional sea sencillo.

**Tú te encargas de tu negocio.
Nosotros nos encargamos de la web.**

Queremos ofrecer una experiencia moderna, rápida y profesional, eliminando la complejidad técnica que normalmente implica mantener un sitio web.

## Tecnología

Evoruna está construido utilizando tecnologías web modernas, priorizando:

* Rendimiento
* Seguridad
* Accesibilidad
* Diseño responsive
* Optimización
* Mantenibilidad
